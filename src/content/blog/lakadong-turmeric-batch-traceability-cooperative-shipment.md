A Certificate of Analysis tells a buyer what a batch of Lakadong turmeric contains. It does not, by itself, tell a buyer where that batch came from, who handled it, or whether the goods in a specific container are actually the goods the paperwork describes. That second question is what batch-level traceability answers, and it is a distinct discipline from quality testing, even though buyers frequently treat the two as the same thing.

This guide covers what lot-coding and chain-of-custody documentation a buyer can realistically request to trace a Lakadong turmeric shipment back toward its originating cooperative or Farmer Producer Organisation (FPO) in West Jaintia Hills, what the practical limits of that traceability are today, and what Meghalaya's new Mission Golden Spice programme does and does not change about it.

---

## Traceability Is a Documentation Chain, Not a Single Certificate

Batch or lot-level traceability means that a single identifying reference - a lot number, batch code, or run identifier - appears consistently across every stage of documentation for a defined quantity of goods: the raw material intake record, the processing log, the quality test result, and the shipping paperwork. When that reference is consistent end to end, a buyer receiving a container can, in principle, work backward from the packing list to the specific processing run and the aggregation point that supplied the raw material for it.

This is different from a supplier simply stating that their turmeric "comes from West Jaintia Hills" or providing a Certificate of Analysis that references a generic product specification rather than a specific run. General origin claims and generic CoAs are common in the trade, and they are not worthless, but they do not constitute batch-level traceability. A buyer who needs to demonstrate origin and chain of custody for a regulatory submission, a retail partner's due diligence process, or their own quality investigation needs the lot reference to actually connect the documents, not just describe the region.

## Where the Lot Code Originates

In a typical Lakadong turmeric supply chain, raw rhizomes move from individual farmers to a cooperative or FPO collection point, then to a processor for drying and grinding, then to an exporter for documentation and shipment. A lot code can, in principle, be assigned at any of these points, but where it is assigned determines how far back a buyer can actually trace.

**Cooperative or FPO intake level.** Some cooperatives maintain intake registers recording the date, approximate quantity, and source village or grower group for material received. Where this practice exists, a lot code assigned at the processing stage can be cross-referenced back to a bounded set of intake records covering a specific collection window. This is the most common level at which genuine traceability is available in practice.

**Individual farmer level.** Farm-level traceability, where a lot code traces to a single named grower's plot, is achievable but not universal. It requires the cooperative to maintain farmer-specific intake logs rather than pooling material on receipt, and it is more commonly found where a cooperative has invested specifically in origin-story or premium-marketing capability, since farm-level traceability is a marketing asset as much as a compliance one.

**Processor level only.** In pooled aggregation models, raw material from multiple cooperatives or collection points may be combined before a lot code is assigned at the processing stage. In this model, a buyer can trace a batch back to a processing run and a general collection region, but not to a specific cooperative or farmer group, because that granularity was lost at the point of pooling.

Buyers should ask directly, before placing an order, which of these three models a specific supplier operates under. The answer determines what a lot code can and cannot demonstrate later.

## What to Request as Documentary Evidence

A buyer seeking working, checkable traceability - as opposed to a general assurance - should request the following, referenced to the same lot or batch identifier:

**The intake or collection record.** Even a simple register entry showing date, approximate quantity, and collection point or cooperative name for the raw material behind a specific lot gives a buyer something to check against later, and its absence is itself informative.

**The processing log.** A record of the drying or grinding run, including date and the lot code it was assigned, connects the raw material stage to the finished-goods stage.

**A lot-referenced Certificate of Analysis.** The CoA should state the lot or batch number on its face, not just a general product specification. A CoA that cannot be matched to a specific lot number is evidence about a hypothetical typical batch, not the goods actually being shipped.

**Packing list and shipping documentation cross-reference.** The lot number appearing on the CoA should also appear on the packing list and, ideally, on the physical packaging itself, so the paper trail can be checked against the goods on arrival.

**A documented explanation of any reference changes.** If the identifying number changes between stages - for example, an internal cooperative code becoming a different processor lot number - ask for a cross-reference document showing how the two map to each other. A silent change in reference number, with no documented link, is the single most common way a traceability chain breaks down without anyone noticing until a problem occurs.

None of this requires exotic technology. A supplier with disciplined paper or spreadsheet-based record-keeping that consistently carries a lot reference through each stage can provide meaningful traceability. Conversely, a supplier with a sophisticated-sounding system that cannot actually produce a consistent lot reference across documents is not providing traceability, regardless of how the system is described.

## What Mission Golden Spice Changes, and When

In July 2026, the Government of Meghalaya launched Mission Golden Spice, a five-year, government-backed Lakadong turmeric value chain programme built around a Community-Public-Private Partnership model. Alongside cultivation expansion, processing infrastructure, and FPO development, the programme's published funding allocation includes state investment specifically earmarked for blockchain-based GI traceability and export systems, alongside branding and FPO working capital support.

This is a genuine development, and it is worth distinguishing clearly what it means today from what it is intended to mean once built out. As of the programme's launch, the blockchain traceability component is a funded commitment within a five-year infrastructure programme, not an operating platform that a buyer can currently query to verify a specific shipment. Buyers should treat it the way they would treat any infrastructure investment still in early implementation: relevant to plan around for future sourcing relationships, but not something to assume is already live for a shipment being quoted today.

The practical implication for a buyer sourcing now is unchanged from the guidance above: ask the specific supplier what traceability documentation they can provide for this shipment, at which stage a lot code is assigned, and how far back it actually traces. As the programme's infrastructure comes online over its five-year timeline, buyers working with FPOs and processors connected to it may see that documentation increasingly formalised through a digital system rather than paper registers - but the underlying discipline a buyer should verify does not change: does the lot reference actually connect the goods to the documented origin, consistently, end to end.

## A Practical Checklist Before Placing an Order

- Ask which traceability model the supplier operates: cooperative-level, farmer-level, or processor-pooled
- Request a sample intake record or processing log referencing the lot code, not just a general description of practice
- Confirm the CoA states the specific lot or batch number, not a generic specification
- Confirm the same lot reference appears on the packing list and, ideally, on physical packaging
- Ask directly whether any reference number changes between stages, and request the cross-reference document if so
- If your use case requires farm-level traceability specifically, confirm this in writing before ordering rather than assuming it is available

## Frequently Asked Questions

**What is a lot or batch code in Lakadong turmeric sourcing?**

A lot or batch code is an identifier assigned to a specific, bounded quantity of turmeric processed together, usually corresponding to a single drying or grinding run from a defined intake of raw material. It links the physical goods in a shipment to the paperwork trail behind them: the intake record at the cooperative or aggregator, the processing date, and the Certificate of Analysis for that specific run. Without a lot code tying goods to documentation, a Certificate of Analysis is only a general quality claim, not evidence about the specific bags in a container.

**Can a buyer trace a Lakadong turmeric shipment back to a specific cooperative or farmer group?**

In most cases a buyer can trace a shipment back to the aggregating cooperative or Farmer Producer Organisation (FPO) and the general collection area, since intake registers at that level are common practice. Tracing back to an individual farmer's plot is rarer and depends on whether the specific cooperative maintains farmer-level intake logs rather than pooled village-level records. Buyers who need farmer-level traceability for a specific compliance or marketing purpose should ask this question directly before ordering, rather than assuming it is available by default.

**What documents should connect a lot code across the supply chain?**

A complete chain should show the same lot or batch reference appearing on the cooperative or processor intake record, the internal processing log (drying or grinding date and run), the Certificate of Analysis, the packing list, and the shipping documents including the Certificate of Origin. If the reference number changes at any handoff point without a documented cross-reference, that is a gap in the chain, not a paperwork formality, and it should be raised with the supplier before the goods are accepted.

**Does Mission Golden Spice add a digital traceability system for Lakadong turmeric?**

Yes, in part. Mission Golden Spice, the Government of Meghalaya's five-year Lakadong turmeric value chain programme launched in July 2026, allocates state funding toward blockchain-based GI traceability and export systems alongside FPO packhouse infrastructure. As of the programme's launch, this traceability system is a funded commitment rather than an operating platform buyers can query today, so buyers should ask suppliers directly whether a given shipment is covered by it rather than assuming coverage from the programme announcement alone.

**What should a buyer do if a supplier cannot provide lot-level chain-of-custody documentation?**

Treat it as a sourcing risk to be priced and managed, not necessarily a disqualifying issue. Some legitimate exporters work through pooled aggregation where farm-level or even cooperative-level lot separation is not maintained. Buyers should decide upfront whether their use case (a nutraceutical claim, an ESG questionnaire, a retail origin story) requires documented lot-level traceability, and select suppliers accordingly rather than discovering the gap after a shipment has already been accepted.
